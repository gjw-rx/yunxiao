# model-switching Specification

## Purpose
定义 `/model` 斜杠命令切换当前默认模型的交互契约：仅列出已启用模型并标注默认项、持久化默认模型并重建 LLM Provider、切换不影响进行中的流式回复、API Key 不下发 Webview。

## Requirements
### Requirement: /model 命令切换当前默认模型
系统 SHALL 提供 `/model` 斜杠命令用于切换当前默认模型：选中后弹出模型选择列表，仅列出已启用（`enabled`）的模型并标注当前默认项；用户选择后 SHALL 将所选模型持久化为默认模型（写回模型配置文件），并重建 LLM Provider 使后续新发送的消息使用新模型。

#### Scenario: 选中 /model 弹出模型选择列表
- **WHEN** 用户通过命令菜单选中「切换模型」（`/model`）
- **THEN** 扩展侧弹出模型选择列表，仅包含已启用模型，且当前默认模型被标注

#### Scenario: 选择模型后切换并持久化
- **WHEN** 用户在模型选择列表中选择一个已启用模型
- **THEN** 该模型被持久化为默认模型，对话面板头部模型名更新，之后新发送的消息使用该模型

#### Scenario: 无可用模型时提示且不切换
- **WHEN** 用户触发 `/model` 但不存在任何已启用模型
- **THEN** 扩展侧提示用户先配置模型（引导打开设置页），且不执行任何切换

### Requirement: 切换不影响进行中的流式回复
模型切换 SHALL 只影响切换之后启动的对话运行；用户触发切换时若存在进行中的流式回复，该回复 SHALL 继续使用原模型直至结束，不被中断或中途切换。

#### Scenario: 流式回复进行中切换模型
- **WHEN** 模型 A 的流式回复进行中，用户通过 `/model` 切换到模型 B
- **THEN** 当前流式回复继续由模型 A 完成，切换完成后新发送的消息由模型 B 回复

### Requirement: API Key 不下发 Webview
模型选择列表及切换过程 SHALL 只暴露模型的非敏感信息（模型名、Provider、是否默认、是否已配置密钥），SHALL NOT 将 API Key 明文发送到 Webview。

#### Scenario: 模型列表不含密钥明文
- **WHEN** 扩展侧组装模型选择列表
- **THEN** 列表项仅含模型名、Provider 等非敏感字段，不含 API Key 明文

### Requirement: 输入区提供分层模型配置弹层
系统 SHALL 将对话输入区的当前模型按钮作为统一模型配置弹层入口。根视图 SHALL 展示“模型”和“推理强度”两行及各自当前值；模型子视图 SHALL 仅列出已启用模型并标记当前默认模型。弹层 SHALL 使用 VS Code 主题颜色，在窄视口内保持可见，并对长模型名提供省略与完整辅助文本。

#### Scenario: 打开根视图
- **WHEN** 用户点击输入区当前模型按钮且没有流式回复正在进行
- **THEN** Webview 在按钮上方打开根视图，展示当前模型、当前推理强度和进入各子视图的控件

#### Scenario: 浏览模型子视图
- **WHEN** 用户从根视图进入模型子视图
- **THEN** Webview 展示最新的已启用模型列表、Provider 非敏感信息和当前模型标记，并提供返回根视图的入口

#### Scenario: 从弹层切换模型
- **WHEN** 用户在模型子视图选择另一个已启用模型
- **THEN** 宿主持久化新的默认模型，Webview 刷新模型名及该模型记忆的推理强度，之后的新运行使用新模型

#### Scenario: 在窄视口展示长模型名
- **WHEN** 弹层所在视口宽度小于弹层理想宽度或模型名超出可用空间
- **THEN** 弹层宽度受视口约束且不横向溢出，模型名被安全省略并保留可访问的完整名称

### Requirement: 模型配置弹层支持键盘和一致的关闭行为
模型配置弹层 SHALL 提供可访问名称、当前选中状态和键盘焦点。Esc、点击弹层外部或完成有效选择 SHALL 关闭弹层；关闭后 SHALL 将焦点恢复到触发按钮。流式回复期间入口 SHALL 保持禁用。

#### Scenario: 使用 Esc 关闭弹层
- **WHEN** 键盘焦点位于已打开的模型配置弹层且用户按下 Esc
- **THEN** 弹层关闭且焦点回到当前模型按钮

#### Scenario: 点击外部关闭弹层
- **WHEN** 模型配置弹层已打开且用户点击弹层与触发按钮之外的区域
- **THEN** 弹层关闭且不改变模型或推理强度

#### Scenario: 流式回复期间尝试打开
- **WHEN** 当前会话正在流式回复
- **THEN** 当前模型按钮为禁用状态且不会打开模型配置弹层
