# Proposal: UI Refine Chat Panel

## Why

当前聊天面板的 UI 布局存在以下问题：
1. 顶部的"+"按钮（新建会话）位置不直观，与参考设计（Claude Code）不符
2. 缺少通过 @ 符号快速选择文件的功能
3. Agent 选择器占据顶部宝贵空间，布局不够紧凑
4. 会话无法自定义命名，不便于区分多个会话
5. 打开插件需要手动点击"新会话"才能开始，操作繁琐

参考 Claude Code 的界面设计，进行 UI 美化和交互优化，提升用户体验。

## What Changes

- 移除输入框左侧的"+"按钮
- 实现 @ 符号触发文件选择器功能
- 将 Agent 选择器从顶部移动到输入框右下角
- 将"新建会话"按钮优化为图标按钮（+ 新建）和历史按钮（时钟图标）
- 将原 Agent 选择器位置改为可编辑的会话名称输入框
- 打开插件时自动创建新会话，无需手动点击

## Impact

- 受影响文件：`src/chatPanel.ts`（HTML/CSS/JS 都在此文件中）
- 后端 API 无需改动（文件选择使用 VSCode API）
- 用户交互流程改变：打开即可以开始聊天，无需手动新建会话
