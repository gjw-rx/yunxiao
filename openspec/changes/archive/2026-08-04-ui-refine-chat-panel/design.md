# Design: UI Refine Chat Panel

## 布局重构

### 新布局结构（参考 Claude Code）

```
┌─────────────────────────────────────────┐
│  [会话名称输入框]              [🔒] [...] │  ← 顶部栏：会话命名
├─────────────────────────────────────────┤
│                                         │
│           欢迎/消息区域                  │  ← 消息展示
│                                         │
├─────────────────────────────────────────┤
│  输入消息...             🎤              │  ← 输入区
│  [+] [/]        ⚡ Auto [Agent选择] [↑] │  ← 底部工具栏
└─────────────────────────────────────────┘
```

### 详细设计

#### 1. 顶部栏改造
- 移除原 Agent 选择器下拉框
- 替换为可编辑的会话名称输入框（默认显示 "Untitled"）
- 用户可以点击修改会话名称
- 右侧保留锁定和更多按钮（如果需要）

#### 2. 移除顶部 + 号
- 顶部不再显示新建会话按钮
- 新建会话功能移到底部工具栏

#### 3. @ 文件选择功能
- 在输入框中输入 `@` 时触发文件选择下拉菜单
- 下拉菜单显示工作区文件列表，支持搜索过滤
- 选中文件后，在输入框中插入 `@文件名` 标记
- 需要新增消息类型 `pickFile` 从 webview 到扩展，调用 VSCode 文件选择 API
- 后端需要支持解析消息中的 @ 文件引用，自动读取文件内容附加到上下文

#### 4. 底部工具栏布局
参考 Claude Code 设计，输入框下方工具栏：
- **左侧**：+ 图标按钮（新建会话）、/ 图标按钮（预留命令）
- **右侧**：⚡ Auto（模式选择，可保留）、Agent 选择器（原顶部的下拉，改为紧凑图标/小按钮）、发送按钮
- **历史按钮**：在右上角标题栏区域添加时钟图标按钮（历史查看）

#### 5. 自动创建会话
- 插件加载完成、Agent 列表加载后，自动选择第一个 Agent 并创建会话
- 用户打开插件即可直接输入消息，无需手动点击"新会话"

## 技术实现

### HTML 结构变更
在 `_getBodyHtml()` 中：
1. 修改 `#header` 内容：Agent 选择器替换为会话名称输入框，添加历史按钮
2. 修改 `#inputWrapper` 和 `#inputArea`：
   - 输入框左侧保留（移除+号，或者根据参考图调整）
   - 输入框下方新增工具栏行，包含新建会话按钮、Agent 选择器等

### CSS 样式变更
在 `_getCss()` 中：
1. 调整 header 样式适配会话名称输入框
2. 新增底部工具栏样式
3. 新增紧凑版 Agent 选择器样式
4. 新增 @ 文件下拉菜单样式
5. 新增历史面板样式

### JavaScript 逻辑变更
在 `_getJs()` 中：
1. 初始化时：Agent 加载完成后自动调用 `startNewSession()`
2. 新增 @ 检测逻辑：监听 input 事件，检测 `@` 输入
3. 新增文件选择下拉菜单的显示/隐藏/搜索/选择逻辑
4. 新增会话名称编辑功能
5. 新增历史按钮点击事件（显示历史会话列表）
6. 重构 Agent 选择器为紧凑模式，移到底部
7. 新增消息类型：`pickFile`（请求选择文件）、`renameSession`（重命名会话）

### 后端消息处理
在 `_handleMessage()` 中：
1. 新增 `pickFile` 命令处理：调用 `vscode.window.showOpenDialog` 选择文件
2. 新增 `renameSession` 命令处理：保存会话名称（内存中即可，暂不持久化）
3. 现有 `createSession` 逻辑保持，但在初始化时自动触发

## 文件引用
主要修改文件：`src/chatPanel.ts`
- `_getHtml()` - 无需改动
- `_getCss()` - 样式重构
- `_getBodyHtml()` - HTML 结构重构
- `_getJs()` - 交互逻辑重构
- `_handleMessage()` - 新增消息处理

## 依赖
- 无新增外部依赖
- 使用 VSCode 内置的 `vscode.window.showOpenDialog` API 进行文件选择
