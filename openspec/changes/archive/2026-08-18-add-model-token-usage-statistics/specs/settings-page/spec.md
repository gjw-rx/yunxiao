## MODIFIED Requirements

### Requirement: 设置分类与可操作内容
设置页 SHALL 使用左侧分类导航和右侧内容区展示“模型”“Skill”“MCP”“Hooks”“使用情况”五个分类，导航顺序 SHALL 为模型、Skill、MCP、Hooks、使用情况，默认显示“模型”。模型分类 MUST 显示可编辑的模型配置和保存状态；Skill 分类 MUST 显示已加载 Skill 并提供安装操作的状态反馈；MCP 分类 MUST 提供 JSON 配置入口与 MCP Server 列表管理；Hooks 分类 MUST 提供 Hooks 总开关与内置 RTK Hook 的配置、检测和测试反馈；使用情况分类 MUST 通过扩展宿主请求当前工作区真实的本地 token 用量，并提供日、周、月粒度切换、时间段选择、区间总量及按模型明细。使用情况 MUST 明确数据范围为当前工作区本地已记录 token，且 MUST NOT 将其表述为费用或云端账户统计。

#### Scenario: 查看并保存模型配置
- **WHEN** 用户在设置页默认的“模型”分类加载或保存有效配置
- **THEN** 页面显示宿主返回的当前非敏感字段及保存结果，且不会显示 API Key 明文

#### Scenario: 查看 Skill 管理内容
- **WHEN** 用户在设置页点击“Skill”分类
- **THEN** 页面请求并显示当前已加载 Skill，且安装反馈会更新列表或显示失败原因

#### Scenario: 查看 MCP 管理内容
- **WHEN** 用户在设置页点击“MCP”分类
- **THEN** 页面请求并显示当前 MCP Server 快照，并提供 JSON 新增/编辑、启停、重连和删除操作

#### Scenario: 查看 Hooks 管理内容
- **WHEN** 用户在设置页点击位于 MCP 下方的“Hooks”分类
- **THEN** 页面请求并显示 Hooks 总开关、RTK 启用状态、可执行文件路径、检测状态和测试改写反馈

#### Scenario: 查看真实使用情况
- **WHEN** 用户在设置页点击“使用情况”分类
- **THEN** 页面请求并显示当前工作区当前自然日的 token 总量与按模型明细，并允许切换日、周、月粒度及对应时间段

#### Scenario: 切换统计粒度和时间段
- **WHEN** 用户把使用情况从“天”切换为“周”或“月”，或选择相邻时间段
- **THEN** 页面按新粒度和时间段请求快照并替换总量与模型明细，不影响模型、Skill、MCP 或 Hooks 分类的草稿状态

#### Scenario: 使用情况为空
- **WHEN** 所选时间段没有任何已记录 token 账
- **THEN** 页面显示总量为 0 和明确空状态，不显示伪造模型行且不报错

#### Scenario: 使用情况部分数据不可读
- **WHEN** 宿主返回有效统计并标记部分归档无法读取
- **THEN** 页面展示可用数据和数据可能不完整的提示

#### Scenario: 使用情况请求失败
- **WHEN** 宿主无法完成用量统计请求
- **THEN** 页面显示有界中文错误并允许用户重试，其他设置分类保持可操作
