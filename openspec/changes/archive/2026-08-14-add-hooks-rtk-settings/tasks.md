## 3. RTK Transform Hook

- [x] 3.1 实现 RTK 可执行文件检测，使用无 Shell 子进程验证 `--version` 与 `rewrite --help`，返回有界的可用状态、版本和错误摘要。
- [x] 3.2 实现 `terminal_exec` 专用 RTK Transform Hook：以 `spawn(rtkPath, ['rewrite', command], { shell: false })` 调用改写能力，且只允许替换 `command` 参数。
- [x] 3.3 为 RTK 调用实现有界超时和 fail-open 路径；未启用、无匹配、非零退出、缺少二进制、异常或非法输出时保持原命令并记录中文日志。
- [x] 3.4 实现固定 `git status` 样例的改写测试接口，仅返回样例、改写结果或有界错误，且不得执行样例的实际 Git 命令。
- [x] 3.5 确保 RTK Adapter 不调用 `rtk init`、不安装或升级 RTK、不注入模型提示词，并且不影响 `simple-git`、文件、代码和 MCP 工具。
