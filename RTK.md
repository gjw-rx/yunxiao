# RTK - Rust Token Killer (Codex CLI)

## Usage

Always prefix shell commands with `rtk` when an RTK equivalent is available.

Examples:

```powershell
rtk git status
rtk npm run build
rtk pytest -q
```

## Meta Commands

```powershell
rtk gain            # View token savings analytics
rtk gain --history  # View recent command savings history
rtk proxy <cmd>     # Run a raw command without RTK filtering
```

## Verification

```powershell
rtk --version
rtk gain
```
