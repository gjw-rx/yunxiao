# 实施步骤拆解

> 本文档回答：**具体我该怎么去做**。将 VSCode 插件开发拆解为 8 个阶段，每阶段含「做什么 / 怎么验证 / 产出物」，按顺序执行即可落地一个可用的 Agent 对话面板插件。

> 前置阅读：[01-VSCode插件开发指南.md](./01-VSCode插件开发指南.md)、[02-服务集成方案.md](./02-服务集成方案.md)

## 阶段 3：实现服务客户端

### 做什么

新建 `src/aiClient.ts`，封装与服务端的全部交互：

```typescript
import * as http from 'http';
import * as https from 'https';
import { URL } from 'url';

// ---------- 类型定义 ----------
export interface AgentInfo {
    agent_id: string;
    agent_name: string;
    agent_desc: string;
    model?: string;
    memory_enabled?: boolean;
}

export interface MessageInfo {
    id: number;
    session_id: string;
    role: string;
    content: string;
    seq: number;
    create_time: string;
}

interface ApiResponse<T> {
    success: boolean;
    data?: T;
    error?: string;
    message?: string;
}

// ---------- 通用 JSON 请求 ----------
function request<T>(baseUrl: string, path: string, method: string, body?: unknown): Promise<T> {
    return new Promise((resolve, reject) => {
        const url = new URL(path, baseUrl);
        const lib = url.protocol === 'https:' ? https : http;
        const payload = body ? JSON.stringify(body) : undefined;
        const req = lib.request(
            {
                hostname: url.hostname,
                port: url.port,
                path: url.pathname + url.search,
                method,
                headers: payload
                    ? { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(payload) }
                    : undefined,
            },
            (res) => {
                let data = '';
                res.on('data', (c) => (data += c));
                res.on('end', () => {
                    try {
                        const parsed = JSON.parse(data) as ApiResponse<T>;
                        if (!parsed.success) {
                            reject(new Error(parsed.error ?? parsed.message ?? '请求失败'));
                            return;
                        }
                        resolve(parsed.data as T);
                    } catch (e) {
                        reject(new Error(`响应解析失败: ${e}`));
                    }
                });
            }
        );
        req.on('error', reject);
        if (payload) req.write(payload);
        req.end();
    });
}

// ---------- 业务方法 ----------
export class AIClient {
    constructor(private baseUrl: string) {}

    listAgents(): Promise<AgentInfo[]> {
        return request<AgentInfo[]>(this.baseUrl, '/api/agent/config', 'GET');
    }

    createSession(agentId: string): Promise<{ session_id: string; agent_id: string }> {
        return request(this.baseUrl, '/api/agent/invoke/session', 'POST', { agent_id: agentId });
    }

    getHistory(sessionId: string, offset = 0, limit = 50): Promise<MessageInfo[]> {
        const qs = `?session_id=${encodeURIComponent(sessionId)}&offset=${offset}&limit=${limit}`;
        return request<MessageInfo[]>(this.baseUrl, `/api/agent/invoke/history${qs}`, 'GET');
    }

    /** 流式发消息，返回 AbortController 用于中断 */
    streamMessage(
        body: { session_id: string; text: string },
        cbs: { onContent: (t: string) => void; onEnd: () => void; onError: (e: Error) => void }
    ): AbortController {
        // 实现见 02-服务集成方案.md 第 5.2 节 streamMessage 函数
        // 此处省略，完整代码照搬即可
        // ...
        return new AbortController();
    }
}
```

### 怎么验证

## 阶段 4：实现 Webview 聊天面板

### 做什么

新建 `src/chatPanel.ts`，实现 Webview 面板：

1. `createWebviewPanel` 创建面板，`enableScripts: true`。
2. `getWebviewContent()` 返回聊天 UI 的 HTML（消息列表区 + 输入框 + 发送按钮 + Agent 选择下拉）。
3. Webview 内 `acquireVsCodeApi()` 后，发送按钮点击 -> `postMessage({ command: 'sendMessage', ... })`。
4. 监听 `window.message` 事件接收主进程推送的 `replyChunk` / `replyEnd`。

HTML 关键结构示意：

```html
<div id="agent-bar">
  <select id="agentSelect"><option value="">加载中...</option></select>
  <button id="newSessionBtn">新会话</button>
</div>
<div id="messages"></div>
<div id="input-bar">
  <textarea id="input" placeholder="输入消息..."></textarea>
  <button id="sendBtn">发送</button>
  <button id="stopBtn" disabled>停止</button>
</div>
<script>
  const vscode = acquireVsCodeApi();
  // 发送
  document.getElementById('sendBtn').addEventListener('click', () => {
      const text = document.getElementById('input').value.trim();
      if (!text) return;
      vscode.postMessage({ command: 'sendMessage', sessionId: currentSessionId, text });
      // 清空输入、追加 user 气泡
  });
  // 接收主进程消息
  window.addEventListener('message', (e) => {
      const msg = e.data;
      if (msg.command === 'replyChunk') { /* 追加到 assistant 气泡 */ }
      if (msg.command === 'replyEnd') { /* 标记完成、启用发送按钮 */ }
      if (msg.command === 'agentsLoaded') { /* 填充下拉 */ }
      if (msg.command === 'error') { /* 显示错误 */ }
  });
  // 初始化时请求 Agent 列表
  vscode.postMessage({ command: 'requestAgents' });
</script>
```

### 怎么验证

1. `F5` 启动，执行 **AI Agent: 打开对话面板**。
2. 面板打开，UI 正常渲染（消息区、输入框、按钮）。
3. 打开 Developer Tools（`Ctrl+Shift+P` -> **Developer: Open Webview Developer Tools**），确认无 JS 报错。

### 产出物

`src/chatPanel.ts`（面板创建 + HTML 生成 + 消息监听）。

## 阶段 5：打通会话流程

### 做什么

在 `chatPanel.ts` 的 `onDidReceiveMessage` 中串联完整流程：

1. **`requestAgents`** -> `client.listAgents()` -> `postMessage({ command: 'agentsLoaded', agents })`
2. **`createSession`**（用户选 Agent 点"新会话"）-> `client.createSession(agentId)` -> 保存 `sessionId` 到面板状态 -> `postMessage({ command: 'sessionCreated', sessionId })`
3. **`sendMessage`** -> `client.streamMessage({ session_id, text }, callbacks)`：
   - `onContent` -> `postMessage({ command: 'replyChunk', text })`
   - `onEnd` -> `postMessage({ command: 'replyEnd' })`
   - 保存返回的 `AbortController` 供停止使用
4. **`stopStream`** -> `controller.abort()` -> `postMessage({ command: 'replyEnd' })`
5. **`loadHistory`**（可选，会话建立后加载历史）-> `client.getHistory(sessionId)` -> `postMessage({ command: 'historyLoaded', messages })`

### 怎么验证

1. 确保 AI 服务运行且有至少一个已装配的 Agent。
2. `F5` 启动，打开面板。
3. Agent 下拉应显示服务端配置的 Agent 列表。
4. 选择一个 Agent，点"新会话"。
5. 输入消息点"发送"，应看到：
   - user 消息立即出现在消息区
   - assistant 回复逐字流式出现（打字机效果）
   - 完成后发送按钮恢复可用
6. 流式过程中点"停止"，回复应中断。

### 产出物

端到端可用的对话流程。

## 阶段 6：配置与健壮性

### 做什么

1. **读取服务地址**：面板创建时从配置读取 `serviceBaseUrl`，实例化 `AIClient`：

```typescript
function getServiceBaseUrl(): string {
    return vscode.workspace.getConfiguration('aiAgentChat').get('serviceBaseUrl', 'http://127.0.0.1:8002');
}
```

2. **配置变更监听**（可选）：用户改配置后重新初始化 client：

```typescript
context.subscriptions.push(
    vscode.workspace.onDidChangeConfiguration((e) => {
        if (e.affectsConfiguration('aiAgentChat.serviceBaseUrl')) {
            // 重新初始化 client / 提示用户重开面板
        }
    })
);
```

3. **连接错误处理**：所有请求 `catch` 后 `postMessage({ command: 'error', message })`，Webview 展示友好提示：

   - 连接拒绝 -> "无法连接 AI 服务，请确认服务已启动且地址正确（当前：<baseUrl></baseurl>）"
   - 会话不存在 -> "会话已失效，请新建会话"
   - 其他 -> 展示 `error.message`
4. **断流处理**：SSE 连接异常断开时 `onError` 回调 -> 标记回复结束 + 错误提示。

### 怎么验证

1. 关闭 AI 服务，打开面板发消息 -> 应看到"无法连接"提示，而非白屏或崩溃。
2. 修改 Settings 中的 serviceBaseUrl 为错误地址 -> 请求失败有提示。
3. 改回正确地址 -> 恢复正常。
4. 流式过程中手动停掉服务 -> 有错误提示，不卡死。

### 产出物

健壮的错误处理 + 可配置的服务地址。

## 阶段 7：打包分发

### 做什么

1. **更新元数据**：编辑 `package.json`：

   - `version`: `0.0.1`
   - `repository`: 添加内网 Git 仓库地址（`vsce` 要求有此字段或用 `--no-dependencies`）
   - `icon`: 配置 128x128 PNG 图标路径
   - 确保 `README.md` 有基本使用说明
2. **编译打包**：

```bash
# 先确认能正常编译
npm run package

# 打包成 .vsix
vsce package
```

3. **安装验证**：

```bash
# 卸载开发版（如有）
code --uninstall-extension ai-agent-chat

# 安装打包产物
code --install-extension ai-agent-chat-0.0.1.vsix
```

4. **分发**：将 `ai-agent-chat-0.0.1.vsix` 放到团队共享位置，团队成员执行 `code --install-extension` 安装。
5. **版本迭代**：每次发版改 `package.json` 的 `version`，重新 `vsce package`。

### 怎么验证

1. `vsce package` 无报错，生成 `.vsix` 文件。
2. 在一个**未开调试**的全新 VSCode 窗口安装 `.vsix`。
3. 启动 AI 服务，打开面板，完整跑通一次对话流程。
4. 确认 Settings 中可修改服务地址且生效。

### 产出物

`ai-agent-chat-0.0.1.vsix`（可分发的安装包）。
