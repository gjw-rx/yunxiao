# 终端执行与输出工件

## 云效现状

`terminal.exec` 有超时、取消、输出上限、危险正则和前缀白名单；未知命令需审批。输出截断后只保留尾部，完整结果不再可回取。

## OpenCode 做得好

OpenCode 用 tree-sitter 解析 Bash/PowerShell，提取实际命令和路径；外部目录单独请求授权。长输出持续展示预览，完整内容溢出后写入临时工件并在结果中提供路径。

## 差距

前缀白名单不能证明整条 shell 命令安全；正则也难正确处理动态表达式。输出被截断后，Agent 和用户都无法按引用继续查看。

## 建议落点与验收

使用 AST 静态提取命令、重定向和路径；动态语法或工作区外路径一律要求额外确认。建立本地/MinIO artifact 接口，输出结果带预览、截断原因和有效期引用。
