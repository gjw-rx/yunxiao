# 上下文压缩与项目指令

## 云效现状

云端已有 Memory、MessageSanitize、ContextCompression、SystemPrompt 与 Trace middleware；压缩会保护头尾消息并保持工具调用边界。这是云效当前较强的一层。

## OpenCode 做得好

除自动 compact 外，OpenCode 会从全局、项目及被读取文件的祖先目录发现 `AGENTS.md`/`CLAUDE.md`，去重后把适用规则附着到对应消息。规则来源和适用范围可追踪。

## 差距

云效的系统提示词主要来自 Agent 配置，未形成“全局规则 → 工作区规则 → 邻近目录规则 → 用户请求”的显式优先级。模型读取特定文件后无法自动获得同目录规范。

## 建议落点与验收

实现 instruction resolver：规范化工作区内路径、向上查找允许的规则文件、记录来源和 hash，并在首次涉及路径时注入一次。压缩摘要必须标记为背景资料，不能提升为活跃指令。
