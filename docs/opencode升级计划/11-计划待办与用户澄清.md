# 计划、待办与用户澄清

## 云效现状

协议可显示 plan/progress，Webview 可显示审批卡片，但计划和用户回答不是会话内第一类状态；中断后无法从持久待办恢复工作进度。

## OpenCode 做得好

OpenCode 把 `todowrite`、`question`、plan mode/plan exit 设计为正式工具。待办、用户选择与模式切换都在会话中记录，并能受权限策略控制。

## 差距

云效的“计划”更接近模型输出展示，不能成为执行预算、子任务编排或恢复后的下一步依据。

## 建议落点与验收

定义可持久的 Plan、Todo 与 Question 事件；执行型 Agent 在高风险或歧义任务前可进入计划状态，用户答案以关联 run/step 事件续流。重连后必须还原未完成待办和待答问题。
