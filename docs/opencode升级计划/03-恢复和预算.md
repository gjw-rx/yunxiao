# 恢复、重试与执行预算

## 云效现状

插件提供工具超时、取消和重复结果忽略；云端有上下文压缩和工具结果预算。但 session agent 与工具结果幂等记录使用进程内字典，缺少 TTL、容量控制和服务重启恢复。

## OpenCode 做得好

OpenCode 检测连续三次相同工具调用并触发确认；它区分 provider 可重试错误、限流、5xx、上下文溢出，并尊重 `Retry-After`。会话处理器还记录每个 step 的使用量与成本。

## 差距

云效没有统一的最大步骤、总耗时、连续等价调用、token/输出总量预算；单次工具保护无法阻止 Agent 级失控循环。

## 建议落点与验收

云端对 run 强制 step、wall-clock、token/输出和重复调用 hash 预算；插件保持本地超时作为第二道限制。超过任一预算必须产生结构化事件，重启后可查询 pending 工具与已接受结果。
